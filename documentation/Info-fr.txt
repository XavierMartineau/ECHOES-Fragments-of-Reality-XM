1. INTRODUCTION GÉNÉRALE
=========================================================
Titre du projet :  
ECHOES: Fragments of Reality

Genre :  
Expérience interactive cyberpunk futuriste spatiale, puzzle narratif, multi‑dimensionnel.

Concept :  
Le joueur traverse trois dimensions fracturées d’un univers cyberpunk spatial, chacune contenant 30 niveaux d’énigmes ultra‑complexes.
Chaque dimension possède son ambiance, ses mécaniques, ses illusions, ses systèmes, ses clés et ses verrous.

Le joueur est guidé par ECHO, une intelligence consciente fragmentée, survivante d’une civilisation technologique disparue.

Le projet doit exploiter tout ce que HTML, CSS et JS peuvent offrir :

animations avancées

illusions 3D

parallaxe multi‑couches

transitions dynamiques

interactions complexes

responsive complet

multilingue FR/EN

systèmes de progression

systèmes de clés/verrous

narration interactive

UI cyberpunk futuriste

===============================
NIVEAU 1 — ALIGNEMENT PRIMAIRE
===============================
Objectif narratif :  
Le Voyageur découvre les premiers fragments de réalité.
ECHO teste sa capacité à percevoir les motifs.

Objectif mécanique :  
Apprendre l’alignement simple d’éléments holographiques.

Description du puzzle :  
Trois formes géométriques flottent dans l’espace.
Le joueur doit les aligner parfaitement sur une ligne holographique.
Les formes réagissent à la proximité (halo lumineux).

Interactions :

Drag & drop fluide

Halo cyan quand l’élément est bien placé

Glitch rouge si mal aligné

Animations :

Pulsation lente des formes

Ligne holographique vibrante

Effet de résonance à la réussite

Ambiance visuelle :  
Néons blancs, géométrie pure, hologrammes translucides.

Ambiance sonore :  
Synth doux, pulsation lente.

Illusions :  
Perspective légère, profondeur holographique.

Condition de déblocage :  
Toujours accessible.

Dialogue d’ECHO :  
« Ces formes… elles sont les premiers fragments. Aligne-les. Laisse la lumière te guider. »

Lien narratif :  
Introduction à la logique géométrique utilisée dans les niveaux 2, 3, 4.

Version EN courte :  
“Align the primary holographic shapes. Follow the resonance.”

Notes IA VS Code :  
Puzzle simple, interactions fluides, animations minimalistes.

===============================
NIVEAU 2 — SÉQUENCE LUMINEUSE
===============================
Objectif narratif :  
ECHO montre au Voyageur comment la lumière encode la mémoire.

Objectif mécanique :  
Apprendre les séquences lumineuses.

Description du puzzle :  
Quatre piliers holographiques s’allument dans un ordre précis.
Le joueur doit reproduire la séquence.

Interactions :

Clic sur les piliers

Feedback lumineux instantané

Erreur = glitch rouge

Animations :

Lumière pulsée

Effet de vague holographique

Explosion cyan à la réussite

Ambiance visuelle :  
Couloir lumineux, piliers holographiques.

Ambiance sonore :  
Notes synth, échos.

Illusions :  
Léger effet de duplication.

Condition de déblocage :  
Niveau 1 complété.

Dialogue d’ECHO :  
« La lumière est mémoire. Reproduis sa séquence. »

Lien narratif :  
Prépare les puzzles de séquences complexes (niveaux 10, 14, 27).

“Repeat the light sequence. Memory flows through light.”
